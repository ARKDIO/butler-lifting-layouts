# 버틀러 — 한국어 줄바꿈 개선안 (2026-07-23 확정·적용 완료)

> **적용 현황**: typo-guard.css 생성 + 16파일 link 완료 / 슬로건 9건 br-m 삽입(사용자의 "데스크톱 한 줄" 지시에 맞춰 전 건 모바일 전용 개행으로 적용) / h-blk 3건 처리(안면부·이마 = 모바일 br 숨김, 재생세포 = 3행 피라미드. 보톡스는 20자 초과 행이 실재하지 않아 해당 없음) / 둘러보기 선언문 3안 통일 + 가운뎃점 nowrap / 오시는 길 "버틀러입니다" 맞춤법 교정 + l3 개행 사다리.
> **결정 사항**: 안면부 D 제목은 축약안 대신 원문 유지(축약 시 표현이 단정적으로 변해 의료광고 심의 리스크 — 모바일 자동 개행으로 해소).

> 검수 에이전트 + 디자이너 + 퍼블리셔/기획자 3자 산출물 종합.
> 문제: 한국어는 브라우저 기본값에서 아무 글자에서나 줄이 꺾여 단어가 반토막 남.
> 방어막(keep-all)이 오픈페이지 모바일 슬로건에만 있고 소개페이지는 0건 — 마스터에서 상속된 결함.

## 해결 구조 = 3층

1. **CSS 안전장치 (자동, 전 페이지)** — `assets/css/typo-guard.css` 신설, 전 파일에 link 1줄.
   - `word-break:keep-all` — 단어 중간에서 안 자름 (+ `overflow-wrap:break-word`로 긴 영문 오버플로 방지)
   - `text-wrap:balance` — 제목 두 줄을 비슷한 길이로 (h1~h3 + 제목 클래스)
   - `text-wrap:pretty` — 리드문 마지막 줄 한 단어 고아 방지
   - `:where()` 명시도 0으로 깔아 기존 CSS와 충돌 없음 (외관 무손상 원칙)
2. **설계된 줄바꿈 (수동 br, 제목만)** — br은 요소당 최대 1개, 쉼표(대구의 축) 뒤에서만.
   - 반응형 토큰: `br.br-m`(모바일 전용 개행) / `br.br-d`(데스크톱 전용) / `br.br-d2`(≤1280px)
   - 규칙: 행 경계 = 굵기(700) 경계. 700 구간을 br로 찢지 않는다. 행두 쉼표·조사 금지. 마지막 행 1어절 고아 금지.
3. **제작 가이드라인 (신규 페이지·WP용)** — 행당 자수 상한: 히어로 H1 12~14자 / 블록 제목 18~22자 / 리드 30~34자. WP 이관 시 typo-guard.css를 테마 + 에디터 스타일로 등록 → 편집자가 제목을 고쳐도 규칙 유지.

(⏎ = 항상 개행, ⏎ᵐ = 모바일에서만 개행)

## h-blk 20자 초과 4건 처리

- 안면부 D · 이마 D: 데스크톱 현행 유지, 모바일에서 br 숨김 + keep-all 자동 개행
- 고압산소 D: 전 폭 3행 재구성 — "과장된 약속 대신⏎검증된 범위 안의 정직한 안내를⏎먼저 생각합니다" (7/13/7 피라미드, 700행 중앙)
- 보톡스·필러 D: 데스크톱 유지 + 모바일 쉼표 뒤 br 추가 (11/8/12)

## 소개페이지 선언문 — 개행점 사다리

- 둘러보기 "1인 전용 프라이빗 시술실 · 수술실": 개행점 = "프라이빗" 뒤 1곳으로 3안 통일. 데스크톱 단행 + 모바일 2행. "시술실 · 수술실"은 nowrap 묶음.
- 오시는 길 "당신의 아름다움을…버틀러 입니다.": 개행점 사다리 — 1순위 "준비된" 뒤(≤1280px 활성), 2순위 "위해" 뒤(모바일). "버틀러/입니다" 사이 개행 금지. (맞춤법상 "버틀러입니다" 붙임 권장 — 카피 협의 항목)
