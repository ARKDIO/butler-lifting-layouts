## 1. 확정 디자인 규칙 (사용자 피드백 집계 — 절대 준수)

### 컬러
- **포인트컬러(그린 #186133 등 유채색) 사용 금지 — 0회.** 텍스트·버튼·탭·아이콘·포커스 전부.
- 허용 팔레트: 검정 #111 / 근검정 #171B18 / 회색 #8a8a8a·#9a9a9a / 헤어라인 #E8E9EA·#EEF0F1 / 박스 #F5F6F8 / 흰색.
- **웜 뉴트럴 확장 (2026-07-23 확정 — 도산밀리 무드 v3)**: 배경 #FBFAF8 / 박스 #F5F3EF / 헤어라인 #E4E0D8 / 와이어 #EDEAE4 / 웜그레이 텍스트 #8a8378 허용. 시술 서브 9장 + 소개 5장은 `assets/css/mood-v3.css` 공통 적용(Cormorant Garamond 영문 세리프 + 라이트 고딕 한글 + 직각 모서리 + F존 소제목 800). 소개 5장은 웜 hex 치환 완료. **메인은 웜 톤을 기본값으로 확정**(body.tone-d 상시, A/B/C 콘텐츠 시안은 유지). 공통 헤더도 웜 톤(#FBFAF8/#E4E0D8/#1D1B18, 버튼 직각).
- 다크 섹션: 사진 위 어두운 오버레이(rgba(10~52,…, 0.5~0.78)) + 흰 텍스트.
- 강조는 **굵기(700)만**. 형광펜·컬러 하이라이트·컬러 strong 금지.

### 타이포 (여수스노우 실측 기준)
- 제목 위계: 인트로 42px / 블록 36px / 정보존 28→21px. **제목 안 굵기 혼용**이 시그니처: 한 줄 700 + 한 줄 400, 또는 문장 중 핵심 단어만 700.
- 본문 16px/400/행간 1.6, 인트로 본문 20px/400/행간 1.5, 리스트 15~15.5px/**300**/행간 1.85~2.0.
- 히어로: H1 68px/700/행간 1.1 + 서브 21px/400, 간격 7px.
- 폰트: Noto Sans/Noto Sans KR. 클래스: `.h-int .h-blk .h-md .bd .bd-lg .dots .gbox .tag .rno` 재사용.

### 간격·정렬
- **제목→본문 10px(±4).** AI스럽게 벌어진 여백 금지.
- 섹션 패딩 72~110px, 정보존(G~L)은 **26px + 헤어라인**(`.v0z` 패턴).
- 어설픈 정렬 금지: 완전 센터 or 의도적 비대칭(예: `.csplit` 좌제목/우본문). 정보 블록은 좌측 통일.
- 명암 리듬: 다크/라이트 교차 배치 (다크 밴드 연속 금지).

### 구조 규칙
- 히어로: **여백 없는 풀블리드**(이미지 or 색면 — 단 그린 금지). 변형은 타이포·버튼·소메뉴(형제시술 탭) 구조로만.
- B(한줄요약): **이미지/배경 활용한 임팩트** 필수.
- G~L(전후사진~FAQ): 스크롤 낭비 금지 — 컴팩트 존(좌 타이틀 170px + 우 콘텐츠 그리드).
- 스위처 UI(`.sec-chip`, `#comboBar`): 회색·작게·반투명·아웃라인 없음 — 수정하지 말 것.
- 콘텐츠 카피: 기획안(0402 엑셀) 원문 그대로. 전후사진 고지문 유지(의료광고 심의).
- 이미지: `img/` 폴더 내 여수스노우 다운로드본만 사용 (임시 placeholder).

## 2. 작업 범위

12개 섹션(A~L) × 변형 5개(v1~v5) = 60블록 재작업.
각 섹션의 `<div class="variant v1">`~`v5` 내부를 교체. **v0과 스위처 JS·CSS 토큰은 건드리지 않는다.**
새 CSS는 섹션 접두사(`a1- b3-` 등)로 네임스페이스해 충돌 방지.

### 변형 축 (5개가 서로 달라야 하는 지점)
| 축 | 옵션 |
|---|---|
| 배경 | 화이트 / 연회색 #FAFAFB / 다크 포토밴드 / 풀블리드 이미지 |
| 정렬 | 센터 / 좌우 비대칭(csplit) / 좌측 스택 |
| 이미지 | 풀블리드 / 컨테이너 라운드 / 없음(타이포 온리) |
| 구조 | 헤어라인 분할 / 회색 박스 / 리스트 / 그리드 / 탭·아코디언(JS는 기존 data-tabs·data-acc 재사용) |

### 섹션별 방향 메모
- **A 히어로 5종**: 풀블리드 고정. ① 센터(=v0 계열 변형) ② 좌하단 앵커+우하단 CTA ③ 타이포 온리 다크 색면(#171B18) ④ 하단 정보바(탭+CTA 통합) ⑤ 스플릿(50:50 다크패널+이미지)
- **B 5종**: ① 다른 이미지 밴드 ② 밝은 이미지+어두운 텍스트 ③ 타이포 온리 초대형(굵기 혼용) ④ 좌 이미지/우 한줄 ⑤ 풀블리드 얕은 밴드(호리존)
- **C 5종**: 에디토리얼 변주 — 헤어라인 세로/가로, 넘버 크기, 2+1 배치, 다크 1종
- **D 5종**: 풀블리드 좌/우, 오버레이 카드, 타임라인(직후→수개월), 타이포 온리
- **E 5종**: 지그재그 밀도 변형, 탭, 2×2, 아코디언, 가로 스크롤 — 전부 rno 넘버링·태그 유지
- **F 5종**: 포토밴드 변주(정렬/리스트 형식), 라이트 2단, 인용형
- **G~L 각 5종**: `.v0z` 컴팩트 그리드 유지 안에서 우측 콘텐츠 형식만 변형 (박스/라인/2열/아코디언 등). 세로 낭비 금지.

## 3. 에이전트 실행 계획 (Opus 세션)

병렬 4개 에이전트, 같은 파일 충돌 방지를 위해 **각자 HTML 조각 파일로 산출 → 메인이 조립**:

1. **Agent A**: 섹션 A+B (10블록) → `parts/AB.html`
2. **Agent B**: 섹션 C+D+E (15블록) → `parts/CDE.html`
3. **Agent C**: 섹션 F+G+H (15블록) → `parts/FGH.html`
4. **Agent D**: 섹션 I+J+K+L (20블록) → `parts/IJKL.html`

각 에이전트 프롬프트에 반드시 포함:
- 이 PLAN.md 전문 + sub-full.html의 해당 섹션 v0 코드(기준 예시)
- 산출 형식: 변형별 `<div class="variant vN">…</div>` 조각 + 필요한 추가 CSS(`<style data-sec="X">`)

조립 후 검증(메인 세션):
1. 그린 검출: 활성 변형 전환하며 색상 스캔 JS (이전 세션에서 쓰던 스크립트 재사용)
2. 각 섹션 v1~v5 전환 스크린샷 확인 (브라우저 스크롤 이슈 시 `document.body.style.marginTop` 시프트 기법)
3. 간격 감사: 제목→본문 마진, 섹션 패딩 실측
